🤖 BotFlix com n8n
Este projeto utiliza o n8n, uma ferramenta de automação de workflows, para criar um bot que recomenda filmes e séries de forma inteligente.

🚀 O que é o n8n?
O n8n é uma plataforma de automação que permite conectar APIs, serviços e criar fluxos visuais sem precisar escrever muito código.
No BotFlix, ele é usado para:

Integrar com a API de filmes (ex.: TMDB).

Processar requisições dos usuários.

Retornar recomendações personalizadas.

📦 Como usar
Instale o n8n localmente ou use a versão em nuvem.

Importe o arquivo JSON do fluxo disponível neste repositório.

Configure suas credenciais da API (TMDB ou outra).

Execute o fluxo e interaja com o bot.

📂 Estrutura
/workflow.json → Arquivo exportado do n8n com o fluxo do BotFlix.

README.md → Documentação do projeto.

🎯 Exemplo de uso
Pergunta: “Recomende um filme de ação”

Resposta: BotFlix retorna um filme de acordo como vc está se sentindo.
